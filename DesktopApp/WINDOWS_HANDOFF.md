# Windows handoff — текущее состояние

Актуальная эксплуатационная инструкция — README.md; история — HISTORY.md.
Замечания и комментарии по каждому пункту — review.md (26 находок + 11 дополнительных).

## Приоритет при проверке

- При первом запуске включён режим «Только чтение». Изменения/exec разрешаются
  снятием «Только просмотр» внизу слева с математическим подтверждением;
  при разрешённой записи боковая панель алая. Тема также находится в настройках.
- Журнал — отдельный раздел слева, Ctrl+J открывает его. В памяти 1000 блоков,
  файл ротируется. Прежние указания о нижней dock-панели устарели.
- Windows portable.key теперь DPAPI-bound; legacy ключ мигрирует при старте.
  Перенос UserData между разными Windows-пользователями требует нового входа.
- Новые снимки snapshot.py исключают credentials. Полный старый снимок до
  редизайна намеренно сохранён; он остаётся чувствительным архивом.
- Изменения протокола/argv/внутренних таймеров и процессов kubectl/proxy отложены
  и помечены «требует уточнения». Addons и внешний клиент не перерабатывались.
- Проверить в тестовом кластере: отказ PDB для eviction без DELETE fallback,
  минимальные права /scale и patch, dry-run, UID/version при пересоздании,
  HPA, ограниченные логи, stale namespace, реальные метрики и shutdown.

Readonly, 13.11.2026: одно разрешение — одна подтверждённая попытка scale,
YAML/ConfigMap, CPU/RAM, restart или удаления Pod. Режим просмотра возвращается
после завершения, включая ошибки/отказ очереди; отмена не расходует разрешение.
Общий токен операции исключает параллельное использование разрешения из другой
карточки/контекстного меню. Пока операция идёт, readonly можно включить, но нельзя
повторно снять. Terminal — исключение: несколько команд до истечения фиксированной
минуты доступа или ухода с вкладки/карточки. Команды и другая активность таймер
не продлевают. Истечение во время подтверждения сохраняет команду без отправки.
В readonly YAML и ConfigMap доступны для поиска, выделения и копирования, но не
для ввода/вставки/удаления/Undo; черновики при включении readonly не сбрасываются.
